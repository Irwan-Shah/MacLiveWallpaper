# Video Wallpaper for macOS

A lightweight macOS application built with **Swift** that allows you to turn any video on your Mac into a desktop wallpaper.

## About the Project

I noticed that many live wallpaper applications available for macOS require a paid subscription or one-time purchase. Since I wanted a simple way to use my own videos as desktop wallpapers without paying for an application, I decided to build one myself.

This project is a personal macOS application that lets users select any video stored on their Mac and use it as a live desktop wallpaper.

The goal is to keep things simple, lightweight, and convenient without unnecessary features or a cluttered interface.

## Features

- **Custom Video Wallpaper** – Choose any video stored locally on your Mac and set it as your desktop wallpaper.
- **Menu Bar Controls** – Access and manage your wallpaper directly from the macOS menu bar without cluttering the Dock.
- **Automatic Wallpaper Restoration** – The application remembers your last-used wallpaper and automatically restores it when you quit and reopen the application.
- **Simple and Minimal** – Designed with simplicity in mind, focusing on the core functionality without unnecessary complexity.

## Built With

- **Swift** – Application development.
- **macOS** – Target platform.



This is a personal project developed primarily for my own use. Features and improvements may be added over time.
